# GPT Tweaks

一个面向 ChatGPT 网页版的轻量浏览器扩展，提供 `Ctrl+Enter` 发送、Markdown 列表自动续写与缩进、对话节点导航，以及对话的 Markdown 下载与复制。

## 按键行为

| 按键 | 行为 |
| --- | --- |
| `Enter` | 插入换行，不发送 |
| `Shift+Enter` | 保留 ChatGPT 原生换行行为 |
| `Ctrl+Enter` | 发送当前消息 |
| 列表项中按 `Tab` | 缩进一级；有序列表编号从 `1` 开始 |
| 非列表项中按 `Tab` | 不修改内容，也不切换焦点 |
| 列表项中按 `Shift+Tab` | 移动到上一级，并继续该级已有编号 |
| 非列表项中按 `Shift+Tab` | 不修改内容，也不切换焦点 |
| 输入法选字时按 `Enter` | 不干预输入法 |

为了确保只有 `Ctrl+Enter` 负责发送，`Alt+Enter`、`Cmd+Enter` 等其他不含 `Shift` 的 Enter 组合也会被处理为换行。

## 列表自动续写

在输入框中使用以下列表格式并按 `Enter`，扩展会直接在下一行补全标记，不会在列表前后或项目之间插入空行：

- 无序列表：`- 项目`
- 有序列表：`1. 项目`，后续编号会自动递增

当扩展生成一个新的空列表项后，再按一次 `Enter` 会删除该项标记并恢复普通文本输入。顶层列表会回到行首；缩进列表第一次按 `Enter` 时只删除 `- ` 或 `数字. ` 标记，保留原有缩进和光标位置。紧接着再次按 `Enter` 时，不会新增空行，而是在同一行返回上一级列表，并继续该级已有编号；再按一次 `Enter` 才退出顶层空列表。

光标位于列表项中时按 `Tab`，扩展会在列表标记前插入四个空格，使当前项目成为下一级列表；有序列表进入新层级后编号会重置为 `1`。按 `Shift+Tab` 会删除一级缩进，使其返回上一级；有序列表会查找上一个同级项目并使用其后续编号，没有可继续的同级项目时从 `1` 开始。后续按 `Enter` 续写时会保留当前缩进并继续编号。列表以外的 `Tab` 和 `Shift+Tab` 不会修改内容，也不会将焦点移动到其他控件。

## 对话节点导航

ChatGPT 只会在满足内部条件时显示原生的右侧节点导航。本扩展会在原生导航缺失时补充一个同类导航：

- 每个短横线对应一条用户提问。
- 鼠标移入后展开用户提问摘要，移出约 250ms 后关闭。
- 点击短横线或提问摘要可跳转到对应的用户消息。
- 用户提问及其回答共用一个激活节点。
- 对话较长时，导航会自动移动，保持当前节点可见。
- 导航优先使用当前对话分支的 Turn UUID，不依赖消息正文是否仍在 DOM 中。
- 目标消息暂未渲染时，扩展会等待 ChatGPT 的分页或虚拟列表加载后再定位。
- 新消息、分支切换、对话切换和单页应用页面更新后会自动重建节点映射。
- ChatGPT 原生导航存在时扩展不会重复创建导航。

### 历史范围

点击浏览器工具栏中的 GPT Tweaks 扩展图标，可以选择导航显示的历史范围：

- 自动：最多显示最近 100 条用户提问。
- 最近 25 条。
- 最近 50 条。
- 最近 100 条。
- 全部：显示当前对话分支中已知的全部用户提问。

该设置只控制导航节点数量。扩展不会强迫全部对话正文永久驻留在页面中，正文仍由 ChatGPT 按需分页和虚拟渲染。这样可以访问较早节点，同时保留长对话的性能保护。

## Markdown 导出

### 下载单条 AI 回复

将鼠标移动到 AI 回复下方的“复制回复”按钮，或用键盘将焦点移到该按钮，会出现一个只有“下载此对话”选项的小菜单。

点击后会打开另存为窗口并生成 `.md` 文件。该入口只导出这条 AI 回复本身：

- 不包含对应的用户问题。
- 不添加 Session 标题、来源 URL 或导出时间。
- 保留 AI 回复的 Markdown 正文、附件占位信息和能够解析的来源链接。

### 导出 Session

点击浏览器工具栏中的 GPT Tweaks 图标，可以：

- 下载当前 Session 的全部对话。
- 选择一个或多个轮次后下载。
- 将全部或选中的轮次复制为 Markdown。

Session 导出和复制使用完全相同的格式，始终包含所选轮次的用户消息与最终 AI 回复。轮次标题复用对话导航中的用户提问摘要，不受“对话导航历史范围”设置限制。

默认不会导出 ChatGPT 的内部消息。可以分别选择是否包含：

- System 消息。
- Tool 与代码执行消息。
- Thoughts。
- Reasoning 和 reasoning recap。
- 隐藏消息。
- 其他尚未分类的内部消息。

“隐藏消息”是额外的过滤条件。例如，要导出一个隐藏的 System 消息，需要同时勾选“System 消息”和“隐藏消息”。

导出的 Session Markdown 使用以下结构：

```md
# Session 标题

> 导出自 ChatGPT
> 原始会话：……
> 导出时间：……

## 第 1 轮：用户提问摘要

### 用户

……

### ChatGPT

……
```

图片和上传文件不会作为二进制嵌入 Markdown。扩展只保存可以读取到的附件名称、MIME 类型、文件大小和占位说明，避免写入可能过期的 ChatGPT 私有资源地址。

### 被卸载的历史正文

长对话中，ChatGPT 会把离开可视区域的消息正文从 DOM 中卸载。扩展不会只遍历当前页面节点，而是在 ChatGPT 正常加载当前 Session 时读取并净化活动分支数据：

- 根据 `current_node` 只保留当前分支。
- 排除其他分支。
- 默认只导出用户消息和最终 AI 回复。
- 按需保留用户明确勾选的内部消息类型。
- 完整正文只保存在当前标签页内存中，不写入扩展存储。
- 切换 Session 后清空旧会话缓存。

如果扩展没有取得完整 Session 快照，弹窗会要求刷新当前 ChatGPT 对话，不会把当前 DOM 中的少量消息冒充成完整导出。复制按钮旁的单条 AI 回复下载仍可使用当前已渲染的正文作为后备来源。

## 安装

本项目无需构建，可以直接作为“已解压的扩展程序”加载。

### Chrome

1. 下载或克隆本仓库。
2. 在地址栏打开 `chrome://extensions/`。
3. 打开右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择本项目根目录，也就是包含 `manifest.json` 的目录。
6. 打开或刷新 `https://chatgpt.com/`。

### Edge

安装步骤与 Chrome 相同，扩展管理页面地址为 `edge://extensions/`。

## 手动验证

加载扩展并刷新 ChatGPT 页面后，可以按以下顺序检查：

1. 在输入框中输入两段文字，中间按一次 `Enter`，确认只产生换行。
2. 按 `Shift+Enter`，确认仍能正常换行。
3. 输入一段不会造成实际影响的测试文字，按 `Ctrl+Enter`，确认消息被发送。
4. 使用中文或日文输入法选字时按 `Enter`，确认可以正常上屏且不会发送。
5. 输入 `- 第一项` 后按 `Enter`，确认下一行自动出现 `- `。
6. 在顶层空的 `- ` 后再次按 `Enter`，确认标记被删除、光标回到行首且没有新增空行。
7. 输入 `1. 第一项` 后连续添加项目，确认编号依次递增。
8. 在 `- 第一项` 中按 `Tab`，确认整行变为四个空格开头，光标仍位于原来的正文位置。
9. 在编号大于 `1` 的有序列表项中按 `Tab`，确认缩进一级、编号重置为 `1`，且光标仍位于原正文位置；随后按 `Enter`，确认二级列表从 `2. ` 继续。
10. 对二级有序列表项按 `Shift+Tab`，确认返回一级、从上一个一级列表编号继续，且光标仍位于原正文位置。
11. 在二级空的 `- ` 后按一次 `Enter`，确认只删除 `- `，四个缩进空格和其后的光标位置保持不变。
12. 在二级空的 `1. ` 后按一次 `Enter`，确认只删除 `1. `，四个缩进空格和其后的光标位置保持不变。
13. 紧接第 12 步再次按 `Enter`，确认不新增行，而是在同一行出现上一级的后续编号，光标停在新标记之后。
14. 再按一次 `Enter`，确认上一级空标记被删除，光标回到当前行开头。
15. 在第一次退出二级空列表后输入内容，确认不会再自动恢复上一级列表标记。
16. 在普通文本中按 `Tab`，确认内容和焦点均不发生变化。
17. 在顶层列表项和普通文本中按 `Shift+Tab`，确认内容和焦点均不发生变化。
18. 打开没有原生右侧导航的短对话，确认右侧显示节点短横线。
19. 将鼠标移入导航，确认出现提问摘要菜单；移开后确认菜单延迟关闭。
20. 点击不同短横线或提问摘要，确认能够跳转到对应的用户消息。
21. 点击扩展图标并切换历史范围，确认导航数量随设置更新。
22. 打开已有 ChatGPT 原生导航的长对话，确认没有出现重复导航。
23. 将鼠标移到任意 AI 回复的“复制回复”按钮，确认出现只包含“下载此对话”的菜单，且原复制按钮仍可正常使用。
24. 点击“下载此对话”，确认出现另存为窗口；保存后确认文件只包含该条 AI 回复，不包含用户问题或 Session 导出头。
25. 打开扩展弹窗，确认显示当前 Session 标题和完整轮次标题列表。
26. 选择“本 Session 全部对话”并下载，确认 Markdown 包含每轮用户消息与最终 AI 回复。
27. 选择若干轮次后下载，确认只包含所选轮次，并保留它们在原 Session 中的轮次编号。
28. 使用相同选择点击“复制”，粘贴后确认内容与下载模式生成的 Markdown 相同。
29. 分别勾选 System、Tool、Thoughts、Reasoning 和其他内部消息，确认只增加对应类型。
30. 只勾选“隐藏消息”，确认不会自动加入未勾选类型的隐藏内容；再同时勾选某一消息类型，确认其隐藏消息出现。
31. 在较长 Session 的底部刷新页面，确认即使 DOM 只渲染少量历史消息，弹窗仍列出完整活动分支并可导出。
32. 切换到另一个 Session 后重新打开扩展弹窗，确认不会显示前一个 Session 的轮次或正文。

修改扩展文件后，请在扩展管理页面点击本扩展的“重新加载”，并刷新 ChatGPT 页面。

## 实现说明

- 扩展仅在 `chatgpt.com` 域名下注入脚本。
- 在键盘事件的捕获阶段拦截 ChatGPT 的默认发送行为。
- 普通 `Enter` 会被转换为 `Shift+Enter`，复用 ChatGPT 编辑器原生的换行逻辑，不直接修改输入框 DOM。
- 列表续写支持 `-` 和 `数字.` 标记，并保留原有缩进。
- 有序列表进入下一级时从 `1` 开始，返回上一级时会继续该级最近的编号。
- 嵌套空列表通过连续按 `Enter` 逐级退出，不会在返回父级列表时额外创建空行。
- 列表项中的 `Tab` 会增加一级缩进，`Shift+Tab` 会删除一级缩进；其他位置不会修改内容或切换焦点。
- ChatGPT 原生导航存在时扩展不会覆盖它；缺失时才创建自定义导航。
- 自定义导航优先根据对话模型的当前分支生成，并在模型不可用时退回稳定的 Turn DOM 属性。
- 扩展在内存中处理当前活动分支的 Turn UUID、Message ID、用户提问摘要和可选导出正文，不把对话正文写入扩展存储。
- Session 导出从 `current_node` 回溯当前活动分支，不会混入其他分支。
- 用户消息和最终 AI 回复默认导出；System、Tool、Thoughts、Reasoning、隐藏及其他内部消息只在用户明确勾选时加入。
- 单条 AI 回复下载只包含 AI 回复正文，Session 下载和复制才包含用户消息。
- 未渲染的历史正文来自 ChatGPT 页面自身正常加载的会话响应；扩展不会在点击导出时伪造认证信息或重放私有接口。
- 内容脚本只负责生成 Markdown，通过扩展后台调用下载 API 并强制显示另存为窗口。
- 弹窗复制使用 `clipboardWrite` 权限；下载使用 `downloads` 权限；弹窗通过 `activeTab` 与当前 ChatGPT 标签页通信。
- 历史范围使用浏览器的扩展存储保存，因此 `manifest.json` 申请了 `storage` 权限。
- 使用 ChatGPT 的 `#prompt-textarea` 与 `data-testid="send-button"` 定位元素，不依赖随机生成的 CSS 类名。
- 单条回复菜单使用 `data-testid="copy-turn-action-button"`，并以“复制回复”的无障碍名称作为后备定位方式。
- 扩展不会把对话或设置发送给第三方。

ChatGPT 的对话接口、Turn 属性和输入框结构都不属于稳定的扩展 API。如果网页后续修改这些结构，相关适配可能需要同步更新。
